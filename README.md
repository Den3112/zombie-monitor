# Zombie Monitor

Project for monitoring zombie processes.

## Development

This project uses **pnpm** and **Volta** for dependency management.

### Quick Start

```bash
# Install dependencies
pnpm install

# Run the server
pnpm dev
# or
node server.js
```

### Shared Global Tools
The following tools are available globally via Volta:
- `next`
- `tsc` (TypeScript)
- `tsx`
